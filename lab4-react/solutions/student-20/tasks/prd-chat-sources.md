# PRD: Лабораторная 4, студент 20

## Обзор и цель
Два проекта на React и TypeScript: библиотека ChatWindow и SourcesPanel, приложение с примером их совместной работы. Основание: tasks/20.md и README лабораторной.

## Принятые решения (проверка grill-me)
- Что считается ответом ассистента? Локальный детерминированный поиск по трём учебным заметкам и заранее написанный ответ. Настоящий API условием не требуется.
- Как доказать переход к источнику? Нативная ссылка ведёт к полному тексту заметки в приложении.
- Где состояние? Библиотека получает сообщения, источники и обработчик через props. Приложение хранит историю и имитирует задержку; форма хранит только черновик.
- Что при повторной отправке? Во время ответа ввод и отправка заблокированы; пробельный ввод отклоняется.
- Как проверяем? Публичные React-компоненты через DOM и действия пользователя, сценарий приложения, браузер, lint и build обоих проектов.
- Риск: версии зависимостей из примера могут отсутствовать в registry; любые изменения фиксировать явно.

## Функциональные требования
FR-1: ChatWindow отображает messages, isTyping и вызывает onSend с очищенным текстом.
FR-2: SourcesPanel отображает sources: id, title, excerpt, relevance (0–1), url.
FR-3: Приложение ищет ключевые слова локально, отвечает через 700 мс, показывает честную оценку совпадений.
FR-4: При размонтировании незавершённый таймер очищается.

## Вне объёма
Сервер, платный API, авторизация и хранение истории между перезагрузками.

Учебная исследовательская тетрадь: бумажный фон, тёмно-зелёный акцент, двухколоночный рабочий стол. На узком экране — одна колонка.
