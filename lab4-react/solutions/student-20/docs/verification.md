## Конфигурации и границы
Версии зависимостей сохранены в диапазонах примера; lock-файлы включены. Для библиотеки явно добавлены dev-зависимости @eslint/js, globals и @types/node, уже используемые конфигурациями примера. Jest-конфиг перенесён в JS (разрешено заданием), чтобы запуск не требовал дополнительного загрузчика TypeScript. Для связанного пакета Vite использует dedupe React, а Jest — одну копию React из frontend.

Сборки выполняются последовательно: сначала библиотека, затем приложение. При одновременной финальной сборке приложение однажды прочитало промежуточный файл от tsc; после повторного последовательного запуска все проверки прошли.

node_modules, dist, coverage и временные артефакты браузера исключены из Git. Поиск запрещённых конструкций any, require, module.exports и var в исходниках совпадений не дал. Изменения существующего решения лабораторной 3 не затрагивались.

Демо использует локальный поиск по словам, не обращается к внешнему API, не сохраняет историю между перезагрузками. Внешнее ревью выполняется отдельно после публикации PR.
